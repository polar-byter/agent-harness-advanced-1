# Агентная мастерская. Ступень 2: модель внутри приложения

Продолжение курса [Агентная мастерская](https://github.com/polar-byter/agent-harness-workshop). В основном курсе модель работала отдельно - в OpenRouter, VseGPT или Ollama, - а программа отправляла ей сообщения. Здесь модель загружается прямо в программу на Python и работает на процессоре обычного ноутбука с Windows, без сети. С ней мы соберём настоящие приложения: утилиту с окном, которая разбирает журнал из Excel, поиск похожих обращений клиентов, проверку фото из заявки на возврат, локальный веб-сервис, расшифровку голосового сообщения и Telegram-бота.

Из основного курса берём знакомое: сообщения с ролями `system` и `user`, отдельный разбор ответа, гардрейлы, проверку на контрольных примерах, согласие человека перед важным действием и магазин с его регламентом возвратов. Новое - модель как часть программы, модели разных видов (языковая, эмбеддинги, зрение, речь), ответ строго по схеме JSON и устройство приложения, в которое модель встраивается.

## Как здесь учиться

Уроки можно читать прямо на GitHub. Для практики скачайте архив урока по ссылке в статье, распакуйте и откройте папку урока в PyCharm. Можно скачать и весь репозиторий через **Code -> Download ZIP** и открыть нужную папку внутри `exercises`.

В каждом каркасе всё, что написано раньше, уже работает, а текущая функция остановлена на `raise NotImplementedError(...)`. `demo_check.py` проверяет вашу функцию на подставном объекте без модели, `demo.py` запускает настоящую модель, `tests/test_lesson.py` содержит готовые тесты. [Исходники всех каркасов](exercises/README.md) можно смотреть в браузере.

## Что понадобится

Windows 10 или 11 x64, 8 ГБ оперативной памяти (лучше 16), около 5 ГБ на диске под модели, Python 3.14 и PyCharm. Видеокарта не нужна. Библиотеки ставятся готовыми пакетами, модели скачиваются скриптом `get_models.py` в общую папку и используются всеми уроками.
