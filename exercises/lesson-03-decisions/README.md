# Модель, которая принимает решения

Модель отвечает на вопросы об обращении клиента вероятностями: в какую очередь его отправить и
просит ли клиент вернуть деньги. Решение по этим вероятностям принимает программа. Вопросы
записаны в формате Jev от TypeSafe AI, а отвечает локальная Qwen3.

1. Откройте эту папку в PyCharm через File -> Open и выберите общий интерпретатор курса.
2. Установите зависимости: `python -m pip install --only-binary=:all: -r requirements.txt`.
3. Запустите get_models.py: если языковая модель из первого урока уже скачана, ничего не загрузится.
4. Допишите ask_choice в decisions.py по TASK.md.
5. Запустите demo_check.py, затем demo.py.
6. Если у вас есть ключ API TypeSafe, запустите demo_jev.py: те же вопросы ответит настоящий Jev.

После реализации demo_check.py выводит:

```text
Проверка без модели: Списали деньги дважды за один заказ -> оплата, уверенность 0.97
```

Проверки: tests/test_lesson.py -> class LessonTests -> Run.
