# Модель зрения проверяет фото из заявки

Модель Qwen3-VL получает фото и название заказанного товара, а программа по её ответу
решает, куда направить заявку на возврат. Деньги по-прежнему возвращает сотрудник.

1. Откройте эту папку в PyCharm через File -> Open и выберите общий интерпретатор курса.
2. Установите зависимости: `python -m pip install --only-binary=:all: -r requirements.txt`.
3. Запустите get_models.py: скачаются два файла модели зрения, всего около 1,6 ГБ.
4. Допишите check_photo в photo_check.py по TASK.md.
5. Запустите demo_check.py, затем demo.py. Каждое фото модель разбирает несколько секунд или дольше.

После реализации demo_check.py выводит:

```text
Проверка без модели: сотруднику: на фото видно повреждение
```

Проверки: tests/test_lesson.py -> class LessonTests -> Run. Источники фото - в data/photos/SOURCES.md.
