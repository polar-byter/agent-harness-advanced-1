# Исходники каркасов

Здесь можно открыть код каждого каркаса прямо на GitHub. Для практики скачайте архив из урока или весь репозиторий через **Code -> Download ZIP** и откройте нужную папку в PyCharm с общим окружением курса.

В каждой папке: `README.md` с порядком запуска, `TASK.md` с подсказками, `local_llm.py` - общий модуль загрузки моделей, `get_models.py`, `requirements.txt`, текущие модули, `demo_check.py` для проверки без модели, `demo.py` для запуска с моделью и `tests/test_lesson.py`.
