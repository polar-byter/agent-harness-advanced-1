# Похожие обращения по смыслу

Модель эмбеддингов превращает текст обращения в вектор. По близости векторов программа находит
обращения о той же проблеме, даже когда в них нет общих слов.

1. Откройте эту папку в PyCharm через File -> Open и выберите общий интерпретатор курса.
2. Установите зависимости: `python -m pip install --only-binary=:all: -r requirements.txt`.
3. Запустите get_models.py: скачается модель эмбеддингов, около 640 МБ.
4. Допишите find_similar в similar.py по TASK.md.
5. Запустите demo_check.py, затем demo.py.

После реализации demo_check.py выводит:

```text
Проверка без модели: Чайник сломался через неделю, верните оплату
```

Проверки: tests/test_lesson.py -> class LessonTests -> Run.
