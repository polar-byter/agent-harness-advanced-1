# Модель внутри программы

Первый урок второй ступени. Здесь модель загружается прямо в программу на Python
через llama-cpp-python, без Ollama и без облачного сервиса.

1. Откройте эту папку в PyCharm через File -> Open.
2. Выберите общий интерпретатор курса (как его создать, описано в уроке) и установите зависимости:

```powershell
python -m pip install --only-binary=:all: -r requirements.txt
```

3. Запустите check_install.py, затем get_models.py: модель скачается в общую папку курса.
4. Допишите ask в local_llm.py по TASK.md.
5. Запустите demo_check.py: здесь настоящая модель не нужна.
6. Запустите demo.py: ответ модели появится в нижней панели Run.

После реализации demo_check.py выводит:

```text
Проверка без модели: Вернуть товар можно в течение 14 дней.
```

Проверки: tests/test_lesson.py -> class LessonTests -> Run.
