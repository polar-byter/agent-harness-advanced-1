# Журнал проделок кота

Десктопная утилита на tkinter: читает журнал из Excel, разбирает записи локальной моделью
и записывает результат на новый лист.

1. Откройте эту папку в PyCharm через File -> Open и выберите общий интерпретатор курса.
2. Установите зависимости: `python -m pip install --only-binary=:all: -r requirements.txt`.
3. Если модель ещё не скачана, запустите get_models.py.
4. Допишите classify_entry в journal_ai.py по TASK.md.
5. Запустите demo_check.py, затем demo.py. Окно утилиты открывает app.py.

После реализации demo_check.py выводит:

```text
Проверка без модели: Стащил со стола котлету, пока все смотрели телевизор -> кухня, серьёзность 1
```

Проверки: tests/test_lesson.py -> class LessonTests -> Run.
