# Учебное дообучение на библиотечных обращениях

Это самостоятельный маленький пример для дополнительного урока. Набор составлен специально для него. Книги и разговоры вымышлены; персональных записей здесь нет.

Модель: `Qwen/Qwen3-0.6B`, ревизия `c1899de289a04d12100db370d81485cdf75e47ca`. Проверены подготовка, разделение данных, маска обучающего ответа, синтаксис скриптов. Обучение весов и сравнение моделей на этом наборе не выполнялись. В архиве нет обученного адаптера и обещанного прироста качества.

## Начать без видеокарты и моделей

```powershell
python check_data.py
python prepare_data.py --output data-rebuilt
```

В `data` лежит уже подготовленный набор: 36 обучающих, 9 проверочных и 9 экзаменационных строк. `data-rebuilt` будет его воспроизводимой копией. Второй запуск с тем же именем папки остановится, чтобы не затереть прежний набор.

## Файлы

| Файл | Назначение |
|---|---|
| prepare_data.py | Создать синтетические примеры и разделить шаблоны |
| data_contract.py | Общая инструкция, формат ответа и подготовка токенов |
| check_data.py | Четыре проверки без нейросети |
| get_model.py | Скачать закрепленную ревизию модели |
| train_adapter.py | Учебный цикл LoRA на NVIDIA CUDA |
| evaluate_adapter.py | Сравнить базу и адаптер на CPU или CUDA |
| data/manifest.json | Размеры частей и контрольные суммы |

Полная инструкция и объяснение математики находятся в дополнительном уроке курса. Окружение обучения создается отдельно от общего окружения семи основных уроков. Пакет PyTorch устанавливается по инструкции для конкретной видеокарты с pytorch.org, затем устанавливаются зависимости из requirements.txt. Их диапазоны являются требованиями примера, а не опубликованным результатом проверки всех сочетаний версий.

```powershell
python -m pip install -r requirements.txt
python get_model.py
python train_adapter.py --base models/qwen3-0.6b --output runs/attempt-01
python evaluate_adapter.py --base models/qwen3-0.6b --adapter runs/attempt-01/adapter --data data/dev.jsonl --device cpu --output runs/dev-cpu.json
```

После выбора настроек проводится отдельный экзамен `data/exam.jsonl`. Если его результаты использованы для следующего исправления, он становится регрессионным; для новой честной оценки потребуется новый закрытый набор.
