## В чем практический смысл задачи?

Во втором уроке мы создали настольную утилиту для журнала кота Барсика. Но у десктопного приложения есть бытовое ограничение: оно работает на одном компьютере. Если кот стащил сосиску на кухне при бабушке, ей приходится идти в комнату и открывать ноутбук.

Гораздо удобнее написать боту в Telegram прямо с телефона:
1. Кто угодно из членов семьи пишет боту короткое сообщение: *"Кот уронил горшок с цветком на балконе"*.
2. Бот мгновенно классифицирует запись локальной нейросетью ("порча вещей", серьезность 2).
3. Дописывает новую строчку в общую таблицу Excel.
4. Отвечает в чат подтверждением.
5. А вечером по команде `/summary` присылает красивый структурированный отчет за день!

---

## Архитектура Telegram-бота: как он работает без белого IP-адреса?

Для запуска нашего бота не нужны аренда серверов, доменные имена, открытые порты или публичный IP-адрес.

Бот использует технологию **Long Polling (длинный опрос)**:
1. Ваш скрипт Python сам подключается к серверам Telegram и держит открытое соединение, спрашивая: *"Есть ли новые сообщения для меня?"*.
2. Как только пользователь отправляет сообщение боту, сервер Telegram мгновенно отдает его вашему скрипту.
3. Скрипт обрабатывает запрос локальной нейросетью и отправляет ответ обратно в чат.

Бот работает автономно прямо на вашем ноутбуке, пока запущен файл `bot.py`! Если ноутбук был временно выключен, Telegram сохраняет сообщения до 24 часов и передаст их боту при следующем запуске.

## 1. Регистрация бота и получение токена (BotFather)

1. Откройте Telegram и найдите официального бота **`@BotFather`** (с синей галочкой верификации).
2. Нажмите **Start** и отправьте команду `/newbot`.
3. Задайте имя бота (например, `Журнал Барсика`).
4. Придумайте уникальный никнейм на латинице, заканчивающийся на `bot` (например, `barsik_notes_2026_bot`).
5. BotFather поздравит вас и пришлет длинный секретный **токен** вида `1234567890:AA...`.

---

## 2. Безопасность: храним токен вне программного кода

Никогда не вставляйте секретные токены прямо в `.py` файлы! Иначе при первой отправке кода в Git или случайном скриншоте ваш токен попадет в чужие руки.

Мы сохраним токен в изолированную системную папку на компьютере:
1. В Проводнике откройте вашу папку пользователя: `C:\Users\<Ваше_Имя>`.
2. Создайте в ней отдельную папку: `agent-secrets`.
3. Внутри создайте текстовый файл `telegram_token.txt` и вставьте туда одну строчку с вашим токеном от BotFather.

Функция `read_token()` в `bot.py` автоматически прочитает токен из этого безопасного файла или переменной окружения `TELEGRAM_BOT_TOKEN`.

## Белый список (Whitelist): железный контроль доступа

В Telegram любой посторонний человек может найти вашего бота по никнейму. Если оставить бота открытым, любой желающий сможет засорить семейную таблицу Excel.

В нашем проекте безопасность вшита на уровне программного кода:
В файле `data/allowed_users.txt` хранится список разрешенных числовых ID пользователей (по одному на строчку).
* Когда приходит сообщение, декоратор в `bot.py` сверяет `message.from_user.id` со списком.
* Если пользователя нет в файле - бот вежливо отказывает и не пускает сообщение к нейросети и базе данных!

Свой персональный числовой ID вы легко узнаете, отправив боту команду `/id`.

## Напишите код сами

Откройте файл `bot_logic.py` и найдите функцию `handle_text`:

```python
def handle_text(model, journal_path: Path, author: str, text: str) -> str:
    # Защитные проверки на пустой и чересчур длинный ввод уже подготовлены:
    text = text.strip()
    if not text:
        return 'Пришлите непустой текст проделки.'
    if len(text) > 300:
        return 'Слишком длинное сообщение: сократите до 300 знаков.'
    raise NotImplementedError('Допишите handle_text по подсказкам урока')
```

Замените строчку `raise NotImplementedError(...)` следующим кодом и заполните два пропуска `...`:

```python
    entry = classify_entry(model, ...)
    append_entry(journal_path, author, text, extra=(entry['category'], entry['severity']))
    return f'Записал в журнал: {entry["category"]}, серьёзность {...}.'
```

1. В вызов функции `classify_entry` передайте текст сообщения: `text`.
2. В итоговой f-строке после слова "серьёзность" подставьте поле из ответа модели: `entry["severity"]`.

Функция `append_entry` из модуля `journal_io.py` сама добавит в файл Excel строку с сегодняшней датой, именем автора, текстом сообщения, категорией и баллом серьезности!

## 4. Боевой запуск бота в Telegram!

1. Откройте `bot.py` и запустите его (**Run 'bot'**). В консоли появится:
   ```text
   Загружаем Qwen3-1.7B-Q8_0.gguf...
   Бот запущен, разрешённых пользователей: 0
   ```
2. Откройте вашего бота в Telegram и нажмите **Start**. Бот пришлет приветствие.
3. Отправьте команду `/id`. Бот ответит: `Ваш id: 123456789`.
4. Нажмите красный квадрат **Stop** в PyCharm. Откройте файл `data/allowed_users.txt`, вставьте туда ваш числовой ID с новой строчки и сохраните файл.
5. Запустите `bot.py` снова (**Run 'bot'**). Теперь написано: `разрешённых пользователей: 1`.
6. Напишите боту проделку:
   > *"Уснул в коробке из-под обуви и громко сопел"*
   
   В Telegram загорится статус *"печатает..."*, и через пару секунд придет ответ:
   > *Записал в журнал: нежности, серьёзность 1.*
   
7. Отправьте боту команду `/summary`: бот сгенерирует аналитическую сводку по категориям!
8. Откройте `data/journal.xlsx` в Excel: внизу таблицы появилась ваша новая запись! *(Перед следующей отправкой закройте файл в Excel, чтобы Windows не блокировала запись).*
